隐私政策

Mini JapanRail — 全日本铁路实时运行地图

我们收集什么

本站不收集、不存储、不上传任何个人信息。您在使用过程中产生的偏好设置（语言、主题、显示开关、跟随状态等）仅保存在您自己的浏览器本地存储（localStorage）中，用于下次访问时恢复界面状态，不会发送到任何服务器。

数据来源

列车运行数据基于日本全国铁路的计划时刻表构建：由每周定时任务从公开时刻表源抓取，打包为紧凑的静态数据文件随站点发布。页面运行时使用这些本地数据驱动渲染，不依赖实时外部请求。

第三方服务
  • 地图渲染使用开源库 MapLibre GL JS（通过公共 CDN 加载，您的浏览器会向该 CDN 发起请求）。
  • 底图瓦片来自日本国土地理院 / OpenFreeMap / OpenStreetMap 等公开服务，加载时可能向相应服务器请求地图图片。
  • 除上述必要资源外，本站不接入任何广告、统计或追踪脚本。
缓存说明

为加快重复访问速度，部分静态数据可能由浏览器缓存（含 IndexedDB / HTTP 缓存）。这些缓存仅存在于您的设备上，可随时通过浏览器设置清除。

联系方式

如果您对本隐私政策有任何疑问，可通过 GitHub 仓库提交 Issue 与我们联系。
